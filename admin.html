✳ ¿TE APARECE “FALTA CONECTAR LIVEKIT”? VER GUÍA RÁPIDA

LiveKit es el motor que envía audio y video a quienes visitan RALL TV. Solo necesitas conectar una cuenta, sin publicar tus claves.

  1. Abre LiveKit Cloud ↗ y crea un proyecto.
  2. En el panel del proyecto copia URL (wss://...), API Key y API Secret.
  3. En Vercel → Project → Settings → Environment Variables, guarda LIVEKIT_URL, LIVEKIT_API_KEY y LIVEKIT_API_SECRET.
  4. Haz Redeploy en Vercel, vuelve a esta cabina y actualiza la página.

Nunca copies el API Secret en archivos públicos, en GitHub o en el chat. Puede haber cargos según el tráfico de audiencia.
